# 오버워치 전술 도구 조사

2026-11-17 기준으로 공개 소개와 문서를 확인했습니다. 아래 표의 미확인은 공개 설명에서 확인하지 못한 기능을 뜻합니다.

| 제품 | 공개 문서에서 확인한 기능 | 동일 월드의 2D/3D 전환 |
| --- | --- | --- |
| OW2Plant | 탑다운 전장에 영웅을 놓고 셋플레이를 설명하는 보드. [공개 소개](https://d3watch.gg/?p=31208) | 미확인 |
| StatBanana | 층별 탑다운 지도, 영웅 배치, 드로잉, 타임라인, 협업. [공식 튜토리얼](https://overwatch.statbanana.com/tutorial) | 미확인 |
| OWScouter | 전장 위 경로, 위치, 영웅 아이콘 배치와 보드 저장·공유. [Map drawer](https://owscouter.com/map-drawer) | 미확인 |
| Overwatch Tactical Board | 조합, 로테이션, 셋플레이, 맵 장악 계획을 위한 브라우저 보드. [저장소](https://github.com/ysnock404/overwatch-tatical-board) | 미확인 |
| Sightline | 스크림 기록의 탑다운 재생, 위치 및 고지대 지표, 히트맵. [공식 소개](https://sightline.gg/) | 미확인 |

Vertactics의 Phase 2는 하나의 3D 지형으로 탑다운 전환, 원근 카메라 조작, 선택 지형의 높이 유지를 검증하는 데 초점을 둡니다. 기존 도구의 에셋이나 소스는 가져오지 않았습니다.
