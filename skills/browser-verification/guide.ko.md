# 브라우저 검증

[English](SKILL.md)

1. `pnpm build`를 실행한 뒤 프리뷰 서버를 이용하는 `pnpm test:e2e`를 실행한다. 필요한 경우 해당 Playwright 브라우저를 설치한다.
2. 두 보기에서 실제 WebGL 지형을 확인한다. 팬, 회전, 확대, 초기화와 캔버스 지형 선택을 검증하고 전환 후 선택과 높이가 유지되는지 확인한다.
3. 잘림, 클릭 불일치, 디딤면 가독성, 패널과 반응형 화면을 실제 렌더링에서 점검한다. 두 보기에서 캡처하고 브라우저와 해상도를 기록한다.
4. 대상 커밋의 CI 결과를 확인한다. 의존성 누락, WebGL 제약과 테스트 단언 실패를 구분한다.
5. 검증한 동작만 SPEC에서 완료 처리한다. 현재 UI와 일치하는 실제 화면을 README에 사용한다.
