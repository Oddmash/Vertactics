# 단계별 실행과 반영

[English](SKILL.md)

1. `PROMPT.md`와 `SPEC.md`에서 현재 단계와 항목 ID를 찾고 작업 트리와 원격 브랜치를 확인한다.
2. 독립적으로 검토할 수 있는 변경을 선택한다. 기존 작업을 보존하고 실제 애플리케이션 흐름에서 검증한다.
3. 소스 확인, 자동화 실행, 브라우저 재현 중 해당 항목에 필요한 근거가 있는 경우에만 `SPEC.md`에서 체크한다. 검증 명령과 차단 원인을 기록한다.
4. 변경 파일과 공백을 확인하고 커밋을 만든다. 승인된 브랜치에 fast-forward로 반영한 뒤 원격 SHA와 CI를 확인한다.
5. 다음 미완료 항목으로 진행한다. 의존 작업이 막히면 차단 상태를 기록하고 독립 작업을 이어간다.
