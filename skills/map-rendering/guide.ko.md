# 지도 렌더링

[English](SKILL.md)

1. `SPEC.md`의 해당 항목과 `AGENTS.md`의 좌표 규칙을 읽는다. 지도 데이터를 수정하기 전에 필요한 도메인 스키마와 검증을 갱신한다.
2. X는 좌우, Y는 높이, Z는 깊이로 사용한다. 2D에서 북쪽은 −Z다. 지형의 최소 모서리, 메시 중심, 이동 가능한 지면 높이를 구분한다.
3. 도메인 계산은 렌더러와 분리한다. 두 보기에서 장면 데이터, 지형 ID와 선택을 공유하고 모드 전환 시 저장 좌표를 유지한다.
4. 계단 방향과 최고 높이, 겹친 표면, 잘못된 입력과 기존 스키마를 확인한다. 실제 단위 환산을 확인하기 전에는 월드 단위 `u`를 사용한다.
5. 실지도 지형의 출처와 검증 상태를 기록한다. 재현 가능한 검증을 위해 가상 고저차 지도를 유지한다.
